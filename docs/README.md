## 食い違いの調査結果

要件書とモックを項目ごとに突き合わせた記録。実装で参照するときの注意点。

### 要注意：要件書の中で食い違っている

**半期ビューを設けるか。**

| 箇所 | 記述 |
|---|---|
| 5.1 ビュー構成 | 「上期・下期は行のグルーピングで示すため、**半期ビューは設けない**（ストリップに吸収）」 |
| 5.2 のツールバー図 | `│月 週 日 半期 年│` |
| 5.2 の3ペイン図 | `（月／週／日／半期／年）` |

**5.1 の方針が正。**「設けない」と理由つきで明示されている一方、5.2 は構成を示す ASCII 図で、
半期ビューを廃止する前の名残とみられる。ビュー切替は月・週・日・年・一覧の5つにする。

モック側は正しく、`mock-window.html` のビュー切替セグメントに半期は無い。
別途「比較用：旧 半期ビュー」というボタンが残っているが、旧案との対比のために
意図して置かれたもの。

### 解消済み：実働日の通し番号をセルに出すか

**要件書 4.3 が正。月ビューのセルと年ビューには出さない。** マイルストーン表示と
競合し、密度が上がりすぎるため。出す場所はツールバーのサマリー・右ペインの選択日
ヘッダ・週ビューの日付ヘッダ・一覧ビューの日付列の4か所。

`mock-window.html` は初めからこの方針どおりだったが、`mock-sidebar.html` だけが
古い案のままセル右上に番号を置いていた。要件書に合わせて直してある。

### 参考：モックの作り込みが仕様に届いていない箇所

## 要件書のトークン表に載っていない色

要件書 5.6 の表は主要なトークンだけを挙げている。モックはほかにも色を使っており、
実装ではモックの値を採る。

| 用途 | モックの変数 | ライト | ダーク |
|---|---|---|---|
| 一段沈めた面（ホバー、前後の月） | `--bg-sunken` | `#f1f2f5` | `#15181e` |
| 予定のカテゴリ色（緑） | `--ok` | `#2f7d5b` | `#5fb08a` |
| 予定のカテゴリ色（琥珀） | `--amber` | `#c2762b` | `#d59a55` |
| 完了したタスクの文字 | `--done` | `#a3a9b5` | `#5d6472` |

`--desk`（モックの外側の背景）はモック用の色なので実装しない。

## モックから写した月ビューの寸法

要件書には書かれていないが、モックの月グリッドが持っている表示。実装はこれに合わせた。

| 要素 | モック | 内容 |
|---|---|---|
| マス | `padding 3px 5px 4px` / `gap 2px` / `overflow hidden` | 溢れは切る |
| 日付 | `12px` / `weight 500` / 等幅数字 | 前後の月は日付だけ `opacity .4` |
| 祝日名 | `.hol` `10px` / 日曜色 | 日付の下に出す |
| マイルストーン | `.ms` `10px` / `weight 600` / `padding 0 5px` / `radius 3px` | 日付の右で中央寄せ |
| 予定 | `.chip` `11px` / `padding 1px 5px` / `radius 3px` / 左に `3px` の帯 | 「09:00 計画レビュー」と時刻を頭に付ける |
| タスク | `.chip.tk` 丸印 `5px` / 枠 `1.5px` / `gap 5px` | 帯を持たず丸印で区別 |
| 溢れ | `.more` `10px` / 補助色 | 「＋2」で件数を示す |
| ホバー | `.cell:hover` | 面を一段沈める |

前後の月のマスは面を `--bg-sunken` に落とし、**日付の数字だけ**を薄くする。
セル全体を薄くすると予定まで読めなくなる。

## その他、要件書で方針が定まっているもの

- **ビュー別の表示項目 ON/OFF は廃止する**（5.5）。旧データの `settings.show` と
  `settings.fontSize` に相当する設定は作らない。レイアウトの作り込みで解決する
- 設定は残すものが明示されている（5.5）。テーマ、週開始曜日、表示時間帯、通知、
  カテゴリ管理、カレンダーの表示切替と並び順、実働日データの供給元、起動時の表示モード、自動起動
