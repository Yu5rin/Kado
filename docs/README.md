## モックと要件書が食い違っている箇所

モックは要件書 v1.0 より前に描いたもので、一部は要件書で方針が変わっている。
**モックの見た目をそのまま実装すると要件を外す**ので、下記は要件書に従うこと。

### 実働日の通し番号をカレンダーのセルに出すか（解消済み）

**要件書 4.3 が正。月ビューのセルと年ビューには出さない。** マイルストーン表示と
競合し、密度が上がりすぎるため。出す場所は、ツールバーのサマリー・右ペインの
選択日ヘッダ・週ビューの日付ヘッダ・一覧ビューの日付列の4か所。

`mock-window.html` は初めからこの方針どおりだったが、`mock-sidebar.html` だけが
古い案のままセル右上に番号を置いていた。要件書に合わせて直してある
（週ビューと一覧ビューの番号は要件どおりなので残している）。

### その他、要件書で方針が定まっているもの

- **ビュー別の表示項目 ON/OFF は廃止する**（要件書 5.5）。モックの `settings.show` に
  相当する設定は作らない。レイアウトの作り込みで解決する
- **半期ビューは設けない**（要件書 5.1）。モックのツールバーには「半期」があるが、
  年ビューのストリップ形式に吸収する
- 年ビューは**年度単位（4月〜翌3月）**。ストリップとカレンダーの2形式を持ち、
  切り替えは年ビュー内のアイコンボタンで行う（設定画面には出さない）
