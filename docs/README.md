## モックと要件書が食い違っている箇所

モックは要件書 v1.0 より前に描いたもので、一部は要件書で方針が変わっている。
**モックの見た目をそのまま実装すると要件を外す**ので、下記は要件書に従うこと。

### 実働日の通し番号をカレンダーのセルに出すか

| | 内容 |
|---|---|
| モック | 月ビューのセル右上に小さく出す（「このアプリ固有の主役表現」と注記） |
| **要件書 4.3** | **月ビューのセルと年ビューには出さない。** マイルストーン表示と競合し、密度が上がりすぎるため |

出す場所は、ツールバーのサマリー・右ペインの選択日ヘッダ・週ビューの日付ヘッダ・
一覧ビューの日付列の4か所。

### その他、要件書で方針が定まっているもの

- **ビュー別の表示項目 ON/OFF は廃止する**（要件書 5.5）。モックの `settings.show` に
  相当する設定は作らない。レイアウトの作り込みで解決する
- **半期ビューは設けない**（要件書 5.1）。モックのツールバーには「半期」があるが、
  年ビューのストリップ形式に吸収する
- 年ビューは**年度単位（4月〜翌3月）**。ストリップとカレンダーの2形式を持ち、
  切り替えは年ビュー内のアイコンボタンで行う（設定画面には出さない）
